TryDesk

Sambung lewat IP, tanpa internet.

Untuk perangkat di jaringan yang sama (kantor, warnet, rumah). Tidak butuh internet dan tidak lewat server TryDesk.

Di PC yang mau dikontrol (Windows)

  1. Buka Pengaturan → Koneksi, nyalakan Izinkan koneksi langsung dari jaringan lokal. Saat Windows menanyakan izin firewall, centang Jaringan pribadi (Private) lalu klik Izinkan.
  2. Pasang password akses minimal 10 karakter di Pengaturan → Keamanan. Tanpa itu, koneksi lewat IP selalu ditolak.
  3. Catat alamat IP-nya. Alamat ini tampil di Beranda, baris Sambung lewat IP (mis. 192.168.1.20).

Di PC atau HP yang mengontrol

  1. Ketik alamat IP tadi di kolom Masukkan ID atau alamat IP, isi password-nya, lalu klik Hubungkan.

Kalau gagal tersambung

  • "PC tujuan tidak menerima koneksi LAN": sakelarnya belum menyala, atau firewall memblokir. Di PC tujuan buka Keamanan Windows → Firewall → Izinkan aplikasi, centang TryDesk untuk Private, dan pastikan jaringan Wi-Fi/kabelnya diset sebagai jaringan pribadi.
  • "Tidak ada TryDesk yang menjawab": kedua perangkat tidak satu jaringan, atau Wi-Fi tamu/hotspot memisahkan perangkat. Pakai jaringan yang sama atau kabel LAN.
  • Alamat IP berubah setelah router dinyalakan ulang. Cek lagi di Beranda PC tujuan.
  • Koneksi ini memakai port TCP 7171. Firewall pihak ketiga (antivirus) juga harus mengizinkannya.

For devices on the same network (an office, an internet cafe, at home). No internet needed, and nothing goes through a TryDesk server.

On the PC you want to control (Windows)

  1. Open Settings → Connection and turn on Allow direct connections from the local network. When Windows asks about the firewall, tick Private networks and click Allow.
  2. Set an access password of at least 10 characters in Settings → Security. Without it, connecting by IP is always refused.
  3. Note its IP address. It shows on Home, in the Connect by IP row (e.g. 192.168.1.20).

On the controlling PC or phone

  1. Type that IP address in the Enter an ID or IP address box, enter the password and click Connect.

If it doesn't connect

  • "The other PC doesn't accept LAN connections": the switch is off, or a firewall blocks it. On that PC open Windows Security → Firewall → Allow an app, tick TryDesk for Private, and make sure its Wi-Fi/cable network is set to Private.
  • "No TryDesk answered at this address": the devices are not on the same network, or a guest Wi-Fi/hotspot keeps devices apart. Use the same network or a LAN cable.
  • The IP address changed after the router restarted. Check it again on that PC's Home.
  • This connection uses TCP port 7171. A third-party firewall (antivirus) must allow it too.

Siapa yang boleh masuk.

Tanpa password, setiap koneksi harus Anda terima dulu di layar ini. Dengan password, tamu yang tahu password langsung masuk.

Jika diset, orang yang mengontrol PC ini cukup mengetik password ini di kolom Password pada TryDesk mereka (atau saat diminta), mereka langsung masuk tanpa Anda klik Terima. Tanpa password, Anda tetap diminta Terima.
Jika password benar, tidak perlu klik Terima
Jika password akses diset, koneksi dengan password benar langsung diterima tanpa konfirmasi. Matikan bila Anda tetap ingin menekan Terima walau password benar.

Cara PC ini tersambung.

Waktu tunggu, sambung ulang, jalur koneksi, dan sambung lewat IP di jaringan yang sama.

Izinkan koneksi langsung dari jaringan lokal
PC lain di jaringan yang sama bisa tersambung dengan mengetik alamat IP PC ini, tanpa internet. Wajib memakai password akses minimal 10 karakter (Keamanan). Saat pertama dinyalakan, Windows akan meminta izin firewall.
Coba sambung ulang jika koneksi terputus
Otomatis akan mencoba koneksi P2P terlebih dahulu, lalu fallback ke TURN relay. "Relay saja" hanya berfungsi bila server menyediakan TURN.
Batasi bandwidth saat menjadi host agar tidak mengganggu aktivitas internet lain.
Cegah layar mati pada host saat sesi aktif

Tetap bisa dihubungi setelah restart.

Dengan layanan Windows, PC ini tetap bisa dikontrol setelah restart dan saat sesi RDP diputus, dengan ID yang sama. Versi Setup memasangnya otomatis; versi Portable tidak memakai layanan.

Dengan layanan, PC ini tetap bisa dikontrol setelah restart dan saat sesi RDP diputus (jendela RDP ditutup), seperti AnyDesk. ID PC ini tidak berubah. Tanpa password akses, setiap koneksi tetap meminta Terima. Versi Setup memasangnya otomatis.
